# Trees

Implementations and problems on Binary Search Trees (BST) and Threaded Binary Search Trees (TBST) in C++.

## Problems Directory

| Folder | Problem Description | Key Concepts |
|---|---|---|
| **`1/`** | **Library Book Inventory** | Binary Search Tree (BST) insertion, inorder traversal, single/double child node deletion using inorder successor, level-by-level display. |
| **`2/`** | **Exam Cell Roll Numbers** | BST insertion, non-recursive min/max search, non-recursive inorder traversal using stack. |
| **`3/`** | **Hospital Patient Tokens** | BST insertion, counting leaf nodes, level-by-level deletion and display, multi-node sequential deletion. |
| **`4/`** | **Employee ID System** | BST insertion, tree height calculation, non-recursive preorder traversal using stack. |
| **`5a/`** | **Railway Reservation Counter** | Threaded Binary Search Tree (TBST) creation, marking threads vs real children, non-recursive/stack-less inorder traversal, inorder successor search. |
| **`5b/`** | **Courier Parcel Delivery** | Threaded Binary Search Tree (TBST) creation, counting total threads, stack-less & non-recursive preorder traversal. |
| **`6/`** | **Auction Bidding System** | BST insertion, inorder, preorder, and postorder traversals, node deletion. |
| **`7/`** | **Stock Trading Floor Price** | BST insertion, floor search (largest price $\le$ target), node deletion, sorted price display. |
| **`8/`** | **Parking Lot Permits** | BST insertion, level-order traversal (breadth-first), node deletion, updated level-order traversal. |
| **`9/`** | **Cinema Seat Booking** | BST insertion, search with comparison count, node cancellation/deletion, finding parent and sibling nodes. |

## Build & Run

To compile and run any problem (e.g. Problem 1):

```bash
cd 1
g++ main.cpp tbst.cpp -o solution
./solution
```
